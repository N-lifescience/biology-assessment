# 출처·저장·공개 정책

## 출처 우선순위

1. 교육부 고시와 국가교육과정정보센터의 공식 교육과정 원문
2. 학교알리미·학교 홈페이지의 공식 공개 문서
3. 공공 통계·법령·논문 메타데이터
4. 자동 추출·규칙·의미 검색으로 만든 추론 관계

4번은 공식 원문과 같은 등급으로 표시하지 않는다.

## 수집 기록

수집한 문서는 다음 값을 가져야 한다.

- 공식 URL과 문서 제목
- 수집 시각
- SHA-256
- 근거 페이지와 짧은 인용 구간
- 파싱·검토 상태
- 공개 가능 범위

## 공개 경계

- 공개 자료라는 이유만으로 첨부파일 전체를 재배포하지 않는다.
- 웹에는 필요한 근거 구절, 페이지, 공식 원문 링크를 우선 제공한다.
- 웹앱 안의 원문 표는 과목 경계와 개인정보 안전 검토를 통과한 생명과학 수행평가 구간만 HTML 안전 변환본으로 제공한다. 첨부파일 전체나 다른 교과·학생 식별 정보가 섞인 구간은 공개하지 않는다.
- HTML 안전 변환본은 원문 텍스트와 표 구조를 보존하려는 재현본이며 지면 배치·도형·병합 셀 모양이 달라질 수 있으므로, 최종 인용 전 공식 원문과 대조한다.
- 오류·정정·삭제 요청을 접수할 운영 연락 경로를 공개 배포 전에 마련한다.
- 학교별 점수·순위·전체 활동 수와 검증되지 않은 성과를 공개하지 않는다.
- 평가계획은 학교 비교가 아니라 학생 활동·탐구 방법·산출물 패턴으로 일반화한다.
- 출처와 해석이 불명확한 결과는 `검토 필요`로 보낸다.

## 학생 입력

- 탐구주제 자유 입력은 기본적으로 저장하지 않는다.
- 이름·학번·학교명·연락처가 포함된 입력은 외부 AI에 보내지 않는다.
- 운영 데이터와 학생 입력을 같은 저장소에 섞지 않는다.
