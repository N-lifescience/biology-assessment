# 2026 생명과학 수행평가 아이디어 아카이브 — 제품 범위

## 제품 목표

전국 학교알리미 평가계획에서 확인되는 생명과학 수행평가의 실제 경향과 사례를
근거로, 교사가 새 수행평가를 설계하고 바로 사용할 문서까지 만드는 도구를
구축한다. 생명과학Ⅰ(2015 개정)과 그 후속 과목인 생명과학(2022 개정)을 첫
시범 과목으로 삼되, 제품 구조는 2015·2022 개정 과학 교과군과 과학계열
전문교과 전체를 지원한다.

## 핵심 사용자 흐름

1. 교육과정과 과목을 선택한다.
2. 전국 평가계획에서 해당 과목의 수행평가 유형·과제·산출물·평가기준 경향을 본다.
3. 출처가 확인되는 실제 사례를 비교하고 필요한 요소만 선택한다.
4. 수업 여건에 맞게 수행평가를 재설계한다.
5. 교사용 계획서, 학생용 안내지, 루브릭, 채점·피드백 계획을 함께 만든다.
6. 교육과정 정합성, 공정성, 실행 가능성, 과정 증거를 점검한 뒤 내보낸다.

## 주요 기능

### 1. 전국 생명과학 수행평가 경향 탐색

- 2015·2022 개정 교육과정과 과학계열 전문교과 구분
- 과목·학년·학기·지역·학교 유형별 필터
- 탐구, 문제해결, 프로젝트, 발표, 보고서, 포트폴리오, 토론, 제작,
  실험, 생태조사 등 수행 유형 비교
- 위 유형 목록은 확정된 분류 체계가 아니라 출발용 씨앗 목록이며, 실제
  생명과학 평가계획 원문을 집계한 뒤 확장한다.
- 개인·모둠, 수업 내·외 수행, 기간, 산출물, 반영 비율, 평가 요소 분석
- 과목 미검출·추출 실패·교육과정 판별 유보·개설 여부 미확인을 구분

### 2. 근거 기반 우수 사례 라이브러리

- 학교나 학생의 우수성을 서열화하지 않고 설계 품질을 검토
- 과제의 명료성, 과학적 탐구 사고 수준, 과정 관찰 가능성, 산출물 적합성,
  루브릭 정합성, 실행 가능성을 기준으로 선별
- 원문 경로, 학교알리미 출처, 교육과정·과목 판별 근거를 함께 표시
- 그대로 복제하는 예시가 아니라 재설계할 수 있는 패턴 카드로 제공

### 3. 수행평가 설계 스튜디오

교사가 다음 조건을 입력하거나 선택한다.

- 교육과정, 과목, 학년, 단원·성취기준
- 평가 목적과 확인할 과학적 탐구 사고
- 수업 차시와 수행 기간
- 개인·모둠 여부와 사용 가능한 도구
- 학생 수준, 지원 조건, 금지·필수 조건

도구는 다음 산출물을 하나의 설계 묶음으로 만든다.

- 수행평가명과 핵심 질문
- 학생 수행 과제와 단계별 활동
- 제출물과 과정 증거
- 교사용 운영 계획
- 학생용 안내지
- 분석적 루브릭과 채점 기준
- 피드백·재도전 계획
- 결시·미제출·협업·AI 활용 처리 원칙

### 4. 설계 품질 점검

- 성취기준과 평가 과제의 직접 연결
- 단순 암기·자료 정리를 넘어선 과학적 탐구 사고 확인
- 채점 가능한 관찰 증거의 존재
- 평가 요소와 루브릭 수준 진술의 일치
- 수업 시간 안에서의 실행 가능성
- 학생 간 접근성·도구 사용·협업 부담의 공정성
- 생성형 AI 사용 범위와 학생 고유 사고 과정 확인 방법
- 개인정보와 학교 원문의 공개 범위 점검

## 교육과정·과목 범위

- 2015 개정: 통합과학, 과학탐구실험, 생명과학Ⅰ, 생명과학Ⅱ
- 2022 개정: 통합과학1, 과학탐구실험1, 생명과학
- 과학계열 전문교과: 생명과학실험, 고급생명과학

## 개발 단계

1. 데이터 기반 구축: 원문 보존, 전체 과목 탐지, 학교×과목 확인표, 경향 집계
2. 사례 분류 체계: 과제 유형·과학적 탐구 사고·산출물·루브릭·운영 조건 구조화
3. 우수 사례 선별: 의미 기반 검토와 교사 검토용 후보 구성
4. 생명과학Ⅰ·생명과학 시범 설계: 대표 수행평가 묶음과 문서 산출물 완성
5. 전 과목 설계 엔진: 과목별 제약과 성취기준 연결 확장
6. 교사용 화면: 탐색, 비교, 설계, 검토, 내보내기를 하나의 흐름으로 연결

## 모델 사용 원칙

원문 수집, 본문 추출, 과목 탐지, 집계, 무결성 검증은 로컬 규칙 기반으로
처리한다. 모델은 우수 사례의 의미 판단, 과제 재설계, 루브릭 문장 작성처럼
맥락 판단이 필요한 단계에서만 사용한다. 모델 결과는 원문 근거와 결정 규칙을
함께 보여 주고 교사가 최종 승인하도록 한다.

## 현재 데이터 해석 한계

현재 원문은 대부분 2026학년도 1학기 자료이므로 2022 개정 과목 분석에 강하다.
2015 개정 생명과학Ⅱ 등 2025학년도 경향은 역사 자료를 추가 수집한 뒤 별도 분석한다.
과목이 평가계획에서 검출되지 않았다는 사실만으로 학교 미개설을 단정하지 않는다.
설계 스튜디오는 해부실습·살아있는 생물 채집·시약 취급·동물윤리가 언급된 사례
카드에 교사가 알아볼 수 있도록 가벼운 `안전·윤리 주의` 표시를 붙일 수 있다.
